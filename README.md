# Stellar-Cleaning

Stellar-Cleaning é um jogo 2D desenvolvido em grupo para a Feira do Empreendedor na ETEC.

## Sobre o Projeto

Neste jogo, o(a) jogador(a) assume o papel de um(a) aventureiro(a) espacial cuja missão é limpar detritos e poluir menos o universo! O objetivo é promover a conscientização sobre sustentabilidade e responsabilidade ambiental, de forma divertida e educativa.

## Tecnologias Utilizadas

- HTML, CSS, JavaScript
- Phaser 3
